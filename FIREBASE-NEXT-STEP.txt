Before email access control and cross-device cloud sync can be enabled:
1. Create a Firebase project.
2. Register a Web App in Project settings.
3. Enable Firebase Authentication (Email link sign-in).
4. Create a Cloud Firestore database.
5. Supply the Firebase Web App configuration (NOT a service-account private key).
6. Configure Firestore security rules so only the designated admin and explicitly approved emails can access the app data.
